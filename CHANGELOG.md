# Changelog

Todas as mudanças relevantes deste projeto serão documentadas aqui.

## [1.1.0] - 2026-05-03

### Adicionado

- Página 404 para rotas inexistentes.
- Confirmação ao remover favoritos.
- Toasts para feedback de ações.
- Busca por stack com debounce.
- Ordenação de vagas por data, salário e status.
- Campos de acompanhamento: notas, próxima entrevista, contato do recrutador e histórico.
- MSW opcional para mock HTTP em desenvolvimento.
- Testes E2E com verificação de acessibilidade via axe.
- Script para geração de screenshots.
- Configurações de deploy para Vercel e Netlify.
- GitHub Actions, templates de PR/issue e documentação de arquitetura.

## [1.0.0] - 2026-04-30

### Adicionado

- Aplicação Vue 3 com autenticação mockada, dashboard, listagem de vagas, favoritos e pipeline.
- Testes unitários, E2E, Docker, ESLint, Prettier e README inicial.
